About

This is the Vercel-hosted MCP (Model Context Protocol) server for the Startup Valuation library. It provides a JSON-RPC API implementing 80+ valuation formulas from the Startup Valuation textbook by Simon Mak.

API Endpoints

GET /health or /api/health
Health check endpoint - returns API status
POST /api
JSON-RPC 2.0 endpoint for MCP protocol methods:
• initialize - Initialize MCP connection
• tools/list - List available valuation tools
• tools/call - Execute valuation calculations

Available Tools

The API provides two main valuation methods:

  • valuation_dcf - Discounted Cash Flow analysis
  • valuation_market_multiple - Market-based valuation using industry multiples
