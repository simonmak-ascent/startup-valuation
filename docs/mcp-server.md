# MCP Server

The MCP (Model Context Protocol) server exposes the Startup Valuation library as
**14 tools** for AI agents. Each tool folds a family of formulas behind a
`method` argument, so 80+ formulas are reachable without a sprawling tool list.
Connect with Claude Desktop, Cursor, OpenCode, or any MCP-compatible client.

The tool surface is defined once in `src/startup_valuation/mcp/tool_surface.py` and shared by
the stdio server (`src/startup_valuation/mcp/server.py`, generated by
`scripts/generate_mcp.py`) and the hosted HTTP endpoint (`api/index.py`).

## Installation

```bash
pip install startup-valuation[mcp]
```

## Quick Start (stdio mode)

```bash
startup-valuation-mcp
```

The server reads JSON-RPC from stdin and writes responses to stdout.

## Hosted endpoint (Streamable HTTP)

No install or API key required:

```
https://startup-valuation.simonmak.com/api
```

## Connecting

### Claude Desktop

Add to `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "startup-valuation": {
      "command": "python",
      "args": ["-m", "startup_valuation.mcp.server"]
    }
  }
}
```

### OpenCode

Add to `opencode.json`:

```json
{
  "mcp": {
    "startup-valuation": {
      "type": "remote",
      "url": "https://startup-valuation.simonmak.com/api",
      "timeout": 60000
    }
  }
}
```

### Cursor

Add the MCP server URL `https://startup-valuation.simonmak.com/api`, or the
stdio command above.

## Tool Reference

Every tool accepts a `method` argument plus that method's parameters. All tools
are read-only, idempotent, and closed-world. Results are
`{value, method, inputs, assumptions, chapter, formula_number, steps}`.
_The server exposes **14 tools**._

### `valuation_probability` — Probability & Expected Value

Compute expected value and probability-weighted outcomes for startup scenarios: discrete E[X], joint probability of sequential events, probability-weighted value, VC portfolio expected return, Poisson event probability, and continuous E[X] over a range. Method selects the formula.

| `method` value | Computes | Parameters |
|---|---|---|
| `expected_value_discrete` | E[X] = Σ xᵢ·P(X=xᵢ) over a discrete outcome list. | `outcomes`, `probabilities` |
| `joint_probability` | P(total) = Π pᵢ for independent sequential events. | `probabilities` |
| `probability_weighted` | E[V] = Σ pᵢ·Vᵢ. | `outcomes`, `probabilities` |
| `portfolio_return` | E[R] = Σ wᵢ·Rᵢ across a VC portfolio. | `weights`, `returns` |
| `poisson` | P(X=k) = e^-λ λ^k / k! for rare events. | `mean_events`, `k` |
| `expected_value_continuous` | E[X] = ∫ x·f(x) dx over [lower, upper] on the standard normal. | `lower`, `upper` |

### `valuation_time_value` — Time Value of Money

Discount future cash to present value: single future value PV, net present value of a cash-flow stream, and annuity present value. Method selects the formula.

| `method` value | Computes | Parameters |
|---|---|---|
| `present_value` | PV = C / (1+r)^t. | `future_value`, `rate`, `periods` |
| `npv` | NPV = Σ Cₜ / (1+r)^t. | `cash_flows`, `rate` |
| `annuity` | PV = P·[1-(1+r)^-n]/r. | `payment`, `rate`, `periods` |

### `valuation_capm` — CAPM & Cost of Equity

Estimate the cost of equity: standard CAPM, startup-adjusted CAPM with size and illiquidity premiums, and portfolio beta from weighted asset betas. Method selects the formula.

| `method` value | Computes | Parameters |
|---|---|---|
| `capm` | E(R) = Rf + β·(E(Rm) - Rf). | `risk_free_rate`, `beta`, `market_return` |
| `startup_capm` | r = Rf + β·MRP + size premium + illiquidity premium. | `risk_free_rate`, `beta`, `market_risk_premium`, `size_premium`, `liquidity_premium` |
| `portfolio_beta` | βp = Σ wᵢ·βᵢ. | `weights`, `betas` |

### `valuation_core` — Pre-Revenue Core Methods

The textbook's pre-revenue methods: Scorecard, Berkus, Risk-Factor Summation, VC Method (post- and pre-money), and exit terminal value. Use these first for early-stage startups. Method selects the formula.

| `method` value | Computes | Parameters |
|---|---|---|
| `scorecard` | V = V_avg · Σ(wᵢ·sᵢ) across 7 factors. | `average_valuation`, `weights`, `scores` |
| `berkus` | V = Σ factor awards, each capped at $500K. | `sound_idea`, `prototype`, `quality_team`, `strategic_relationships`, `product_rollout` |
| `risk_factor` | V = V_base + Σ(rᵢ·$250K) over 12 risks. | `base_valuation`, `risk_ratings` |
| `vc_post_money` | Post = Terminal / target ROI. | `terminal_value`, `target_return` |
| `vc_pre_money` | Pre = Post - Investment. | `post_money`, `investment` |
| `terminal_value` | Terminal = projected revenue × multiple. | `projected_revenue`, `multiple` |
| `triangulated` | Runs Scorecard and the VC Method together and returns their mean. | `average_valuation`, `weights`, `scores`, `terminal_value`, `target_return`, `investment` |

### `valuation_advanced` — Options & Scenario Analysis

Advanced techniques: Black-Scholes call value, binomial-tree option value, and scenario analysis. Method selects the technique. For a quick expected value over scenarios, prefer valuation_probability with method 'probability_weighted'.

| `method` value | Computes | Parameters |
|---|---|---|
| `black_scholes` | C = N(d₁)S - N(d₂)Ke^(-rT). | `underlying`, `strike`, `risk_free_rate`, `volatility`, `time_to_maturity` |
| `binomial` | Cox-Ross-Rubinstein binomial option value. | `underlying`, `strike`, `risk_free_rate`, `volatility`, `time_to_maturity`, `steps` |
| `scenario_analysis` | E[V] = Σ pᵢ·Vᵢ over named scenarios. | `scenarios` |

### `valuation_comparables` — Comparable Multiples

Market multiples from comparables: P/E, P/S, EV/EBITDA, EV/Revenue, and a regression-adjusted multiple. Method selects the ratio. Use when public comparables exist.

| `method` value | Computes | Parameters |
|---|---|---|
| `pe_ratio` | P/E = market cap / net income. | `market_cap`, `net_income` |
| `ps_ratio` | P/S = market cap / revenue. | `market_cap`, `revenue` |
| `ev_ebitda` | EV/EBITDA = enterprise value / EBITDA. | `enterprise_value`, `ebitda` |
| `ev_revenue` | EV/Revenue = enterprise value / revenue. | `enterprise_value`, `revenue` |
| `regression_multiple` | Multiple = β0 + β1·g + β2·M + β3·S + β4·G. | `intercept`, `growth_rate`, `growth_coefficient`, `market_maturity`, `maturity_coefficient`, `stage`, `stage_coefficient`, `geography`, `geography_coefficient` |

### `valuation_saas` — SaaS Metrics & Valuation

SaaS unit economics and valuation: LTV, CAC, MRR, ARR, net revenue retention, magic number, Rule of 40, CAC payback, and ARR revenue-multiple valuation. Method selects the metric.

| `method` value | Computes | Parameters |
|---|---|---|
| `ltv` | LTV = ARPU × gross margin / churn. | `arpu`, `gross_margin`, `churn_rate` |
| `cac` | CAC = S&M expense / new customers. | `sales_marketing_expense`, `new_customers` |
| `mrr` | MRR = ARR / 12 (reverse of ARR). | `arr_value` |
| `arr` | ARR = Σ monthly subscriptions × 12. | `subscription_values` |
| `nrr` | NRR = (start + expansion) / start, net of churn. | `starting_revenue`, `ending_revenue`, `expansion_revenue` |
| `magic_number` | Magic Number = net new ARR / prior-quarter S&M. | `net_new_arr`, `sm_expense_prior` |
| `rule_of_40` | Score = growth rate + profit margin. | `growth_rate`, `profit_margin` |
| `cac_payback` | Months to recover CAC from gross profit. | `cac`, `mrr_per_customer`, `gross_margin` |
| `revenue_multiple` | Valuation = ARR × multiple. | `arr`, `revenue_multiple` |

### `valuation_marketplace` — Marketplace Metrics

Marketplace health and valuation: take rate, GMV revenue-multiple valuation, buyer retention, and network density. Method selects the metric.

| `method` value | Computes | Parameters |
|---|---|---|
| `take_rate` | Take rate = revenue / GMV. | `revenue`, `gmv` |
| `gmv_multiple` | Valuation = GMV × multiple. | `gmv`, `multiple` |
| `buyer_retention` | Retention = repeat buyers / base-period buyers. | `buyers_period_1`, `buyers_repeat` |
| `network_density` | Density = active buyers × active sellers / total users. | `active_buyers`, `active_sellers`, `total_users` |

### `valuation_fintech` — Fintech Valuation

Value and size fintech business models: payment revenue, lending valuation, payment-processor DCF, and neobank customer-based valuation. Method selects the model.

| `method` value | Computes | Parameters |
|---|---|---|
| `payment_revenue` | Revenue = volume × take rate. | `transaction_volume`, `take_rate` |
| `lending` | V = loan book × ROE × P/E - NPL reserves. | `loan_book`, `roe`, `pe_multiple`, `npl_reserves` |
| `payment_processor` | DCF of payment revenue with a terminal multiple. | `transaction_volume`, `take_rate`, `growth_rate`, `discount_rate`, `terminal_multiple`, `years` |
| `neobank` | Customer LTV × P/E applied to the customer base. | `customers`, `arpu`, `gross_margin`, `churn_rate`, `pe_multiple` |

### `valuation_biotech` — Biotech Pipeline Valuation

Risk-adjusted biotech valuation: peak sales, decision-tree expected value, and full pipeline rNPV across drugs. Method selects the model.

| `method` value | Computes | Parameters |
|---|---|---|
| `peak_sales` | Peak = population × penetration × price × compliance. | `patient_population`, `penetration`, `price`, `compliance` |
| `decision_tree` | EV = Π pᵢ × terminal value. | `probabilities`, `terminal_value` |
| `pipeline` | V = Σ(peak sales × multiple × P_success) / (1+r)^n. | `drugs`, `discount_rate` |

### `valuation_hardware` — Hardware & Unit Economics

Hardware and deep-tech valuation: TRL-risk-adjusted valuation, gross margin, and break-even volume. Method selects the metric.

| `method` value | Computes | Parameters |
|---|---|---|
| `trl` | V = market × share × margin × multiple × (1 - TRL discount). | `market_size`, `market_share`, `margin`, `multiple`, `trl_discount` |
| `gross_margin` | GM = (ASP - COGS) / ASP. | `asp`, `variable_cost` |
| `break_even_volume` | Units = fixed costs / (ASP - variable cost). | `fixed_costs`, `asp`, `variable_cost` |

### `valuation_international` — International Valuation

Cross-border adjustments: purchasing-power parity, country risk premium, and international CAPM. Method selects the adjustment.

| `method` value | Computes | Parameters |
|---|---|---|
| `ppp` | Eₜ = E₀·(1+π_foreign)/(1+π_domestic). | `spot_rate`, `inflation_foreign`, `inflation_domestic` |
| `country_risk_premium` | CRP = sovereign yield - US Treasury yield. | `sovereign_yield`, `us_treasury_yield` |
| `intl_capm` | r = Rf + β·MRP + CRP. | `risk_free_rate`, `beta`, `mrp`, `crp` |

### `valuation_stakeholder` — Stakeholder & Equity Allocation

Allocate value across stakeholders and equity classes: single-round dilution, OPM common stock, PWERM, liquidation value, M&A synergy, employee-option values, vesting adjustment, cash-vs-equity break-even, and asset-based loan capacity. Method selects the model.

| `method` value | Computes | Parameters |
|---|---|---|
| `dilution` | Ownership = before × (1 - investment / post-money). | `ownership_before`, `investment`, `post_money` |
| `opm` | Option-pricing allocation of equity value to common shares. | `enterprise_value`, `liquidation_pref`, `time_to_exit`, `volatility` |
| `pwerm` | Probability-weighted expected return method across exit scenarios. | `scenarios` |
| `liquidation` | V = Σ(asset × recovery rate). | `assets`, `recovery_rates` |
| `risk_adjusted_synergy` | Probability-weighted, discounted M&A revenue + cost synergies. | `revenue_synergies`, `cost_synergies`, `prob_revenue`, `prob_cost`, `discount_rate`, `years` |
| `intrinsic_option` | Intrinsic value = max(0, FMV - strike) × shares. | `strike_price`, `fair_market_value`, `shares` |
| `employee_option` | Probability-weighted employee option value across scenarios. | `scenarios` |
| `vesting_adjusted` | Option value adjusted for vesting schedule and retention probability. | `total_value`, `vested_fraction`, `annual_vest_rate`, `retention_prob`, `years_remaining` |
| `cash_equity_breakeven` | Break-even comparing salary reduction against discounted equity. | `salary_reduction`, `equity_value`, `tax_rate`, `discount_rate`, `years` |
| `max_asset_loan` | Borrowing capacity from asset collateral values. | `cash`, `accounts_receivable`, `inventory`, `equipment`, `real_estate` |

### `valuation_emerging` — Emerging & Alternative Methods

Modern and alternative valuation: SAFE conversion (discount, cap, expected value), token valuation (equation of exchange, NVT), ESG adjustments (rate, premium, discount), Metcalfe network value, data-moat value, and remote-first premium/NPV. Method selects the model.

| `method` value | Computes | Parameters |
|---|---|---|
| `safe_discount` | Price = Series A price × (1 - discount). | `series_a_price`, `discount` |
| `safe_cap` | Price = cap / pre-money shares (cap-based). | `cap`, `series_a_price` |
| `safe_expected` | Expected SAFE value across cap and discount outcomes. | `investment`, `cap`, `discount`, `series_a_valuation`, `series_a_price` |
| `token_value` | Value = (volume × price) / (velocity × supply). | `transaction_volume`, `price_per_tx`, `velocity`, `supply` |
| `nvt_ratio` | NVT = market cap / daily transaction volume. | `market_cap`, `transaction_volume` |
| `esg_rate` | r = base + ESG risk premium - ESG opportunity discount. | `rate`, `esg_risk_premium`, `esg_opportunity_discount` |
| `esg_premium` | Valuation uplift = base × (1 + score × premium per point). | `base_valuation`, `esg_score`, `premium_per_point` |
| `esg_discount` | Valuation reduction = base × (1 - risk score × discount per point). | `base_valuation`, `esg_risk_score`, `discount_per_point` |
| `metcalfe` | V = k · n². | `n`, `k` |
| `data_moat` | Discounted value of monetised proprietary data. | `data_volume`, `data_uniqueness`, `monetization_rate`, `competitive_advantage_years`, `discount_rate` |
| `remote_npv` | Perpetuity NPV = annual savings / discount rate. | `annual_savings`, `discount_rate` |
| `remote_premium` | Valuation premium from cost savings, talent access, and productivity. | `base_valuation`, `cost_savings_pct`, `talent_access_premium`, `productivity_gain` |
