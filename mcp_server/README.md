# Startup Valuation MCP Server

Model Context Protocol server exposing the [Startup Valuation](../README.md) library
as **14 tools** covering 80+ valuation formulas.

The tool surface is defined once in `tool_surface.py` and shared by the stdio
server (`server.py`, generated by `../scripts/generate_mcp.py`) and the hosted
HTTP endpoint (`../api/index.py`).

## Run (stdio)

```bash
pip install -e "..[mcp]"
python server.py
```

## Tools

`valuation_probability`, `valuation_time_value`, `valuation_capm`,
`valuation_core`, `valuation_advanced`, `valuation_comparables`,
`valuation_saas`, `valuation_marketplace`, `valuation_fintech`,
`valuation_biotech`, `valuation_hardware`, `valuation_international`,
`valuation_stakeholder`, `valuation_emerging`.

Each tool takes a `method` argument selecting the formula, plus that formula's
parameters. See the repo `README.md` and `docs/mcp-server.md` for details.
